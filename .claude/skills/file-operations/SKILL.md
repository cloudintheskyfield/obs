# File Operations Skill

Use the str_replace_editor tool to view, create, edit and manage text files.

## Available Tools

### str_replace_editor
- **create**: Create a new file with content
- **str_replace**: Replace content in a file
- **insert**: Insert content at a specific line
- **view**: View file content
